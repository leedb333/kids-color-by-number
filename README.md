# 순서대로 색칠놀이

갤럭시탭 세로 화면에 맞춘 유아용 숫자 색칠 웹앱입니다.
광고·가입·결제·개인정보 수집이 없으며 진행 기록은 사용 중인 브라우저에만 저장합니다.

## 도안 5가지

| 도안 | 색칠 단계 | 독립 터치 영역 |
| --- | --- | --- |
| 경찰차 로봇 변신 | 28 | 135 |
| 소방차 로봇 변신 | 28 | 143 |
| 공룡과 알 | 28 | 99 |
| 알록달록 나비 | 28 | 161 |
| 장미꽃 | 28 | 80 |

경찰차 도안의 원본·SVG 데이터·revision·저장 키는 유지했습니다.
무지개 도안은 이미지·데이터·제작 도구와 관련 검사를 삭제했으며,
업데이트된 앱을 열면 해당 도안의 과거 진행 기록만 정리합니다.
Git의 이전 커밋에는 과거 파일이 남아 있습니다.

## 놀이 방법

1. 원하는 도안을 선택합니다.
2. 현재 안내하는 색상 번호를 찾아 영역을 하나씩 누릅니다.
3. 같은 번호의 영역을 모두 칠하면 다음 색으로 자동 이동합니다.
4. 작은 영역은 확대하거나 힌트를 눌러 찾습니다.
5. 되돌리기, 확인 후 처음부터 다시 칠하기를 사용할 수 있습니다.
6. 완성하면 PNG를 저장합니다.

한 번 방문해 오프라인 준비가 끝나면 인터넷 연결 없이 다시 열고 이어 칠할 수 있습니다.
최초 방문과 앱 업데이트에는 인터넷 연결이 필요합니다. 새 버전이 바로 보이지 않으면
앱이 열린 모든 탭을 닫은 뒤 다시 엽니다. 브라우저 데이터 삭제 시 진행 기록도 사라집니다.

## 도안 제작과 구조

- `src/data/drawings.ts`: 도안 등록 및 목록.
- `src/data/police-car-robot`: 유지하는 기존 경찰차 벡터 도안.
- `src/data/new-drawings`: 새 도안 4개의 닫힌 SVG path·팔레트·숫자·터치 좌표.
- `public/assets/source/<도안 ID>/generated-reference.png`: 내장 ImageGen으로 생성한 원본.
- 같은 폴더의 `manifest.json`: 생성 프롬프트·원본 해시·색상·영역 검토 정보.
- `scripts/new-drawings`: 재현 가능한 도안 변환기와 프롬프트 설정.
- `docs/new-drawings`: 실제 앱의 시작 화면·완성 PNG·모바일 화면 및 검증 결과.
- `src/engine.ts`: 색칠 순서와 진행 기록.
- `src/export.ts`: 같은 SVG의 PNG 저장.
- `vite.config.ts`: 오프라인 캐시 및 도안별 파일 분리.

새 도안은 28개의 서로 다른 HEX를 사용하는 28단계입니다. 검은 윤곽과 일부 고정된
흰색 눈빛은 색칠 단계와 별개입니다. 실제 SVG는 그라데이션·반투명·비트맵 오버레이가
없는 불투명 단색입니다. 생성 원본의 미세한 명암은 영역별 한 색으로 평탄화했습니다.
PNG 경계에는 안티앨리어싱으로 중간 RGB 픽셀이 생깁니다.

## 개발과 배포

Node 24를 사용합니다.

```sh
npm ci
npm run dev
npm test
npm run build
npx playwright install chromium
npm run test:e2e -- --timeout 120000
```

GitHub Actions는 기본 검사·빌드·브라우저 검사를 실행합니다. 화면 전후 비교에 필요한
기준 커밋을 위해 CI는 전체 Git 이력을 가져옵니다. `main`에 병합하면 GitHub Pages에
배포됩니다. PR의 자동 병합은 하지 않습니다.

실제 갤럭시탭에서 배포 후 터치감·화면 배율을 최종 확인해 주세요.
