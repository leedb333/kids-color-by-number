# 순서대로 색칠놀이

React + Vite + TypeScript 기반 어린이용 SVG 순서 색칠 앱입니다. 삼성 갤럭시탭 세로 화면과 큰 버튼을 기준으로 만들었습니다. 광고·가입·결제·분석 SDK·외부 폰트는 없습니다.

## 첫 번째 정식 퍼즐

**「무지개를 바라보는 아이」 — 25색, 43개 터치 영역**을 홈의 대표 도안으로 제공합니다.

대화에 표시된 컬러/흑백 참고 이미지의 구도를 살려 닫힌 SVG path를 수동으로 다시 그렸습니다. PNG를 배경에 표시하는 방식이 아닙니다. 노란 우비와 분홍 장화의 아이, 무지개 여섯 띠, 구름, 나무, 그네, 미끄럼틀, 물웅덩이를 유지하고 그라데이션·잔머리·손가락·풀잎·작은 꽃은 단순화했습니다. 색상은 컬러 참고 이미지에 맞춘 평면 색상이며 원본 픽셀과 일치하는 자동 추출/트레이스 결과는 아닙니다.

각 색상을 모두 칠하면 다음 색상으로 이동합니다. 머리카락 같은 동일 색상의 실루엣은 묶고, 장화 밑창·눈·우비 단추·가느다란 기둥은 비색칠 장식으로 남겨 작은 목표 영역을 줄였습니다. 미끄럼틀의 안쪽 장식은 본체와 함께 칠해집니다. 남은 작은 부분은 확대해서 터치할 수 있습니다. 번호 위치 43개가 실제 해당 영역 위에 있는지도 브라우저에서 검증합니다.

기존 체험용 꽃 도안은 `src/data/test-flower.ts`에 개발/회귀 테스트용으로 보관하며 홈과 정식 카탈로그에서는 숨겼습니다. 예전 체험 기록을 삭제하지 않고 정식 도안의 진행 상태와 분리합니다.

| 도안                   | 색상 수 | 상태                 |
| ---------------------- | ------- | -------------------- |
| 무지개를 바라보는 아이 | 25      | 플레이 가능 · 43영역 |
| 그네 타는 아이         | 24      | 준비 중              |
| 불을 끄는 소방차 로봇  | 30      | 준비 중              |
| 아기 공룡과 알         | 23      | 준비 중              |
| 꽃밭의 알록달록 나비   | 27      | 준비 중              |

## 참고 원본 파일 상태

이미지 모습은 대화에서 확인했지만 현재 실행 환경에는 다운로드 가능한 PNG 파일 경로나 첨부 ID가 제공되지 않았습니다. **원본 PNG 두 개의 프로젝트 복사는 아직 완료되지 않았습니다.** 생성 이미지나 스크린샷을 원본으로 위장해 저장하지 않았습니다. 이 제약은 SVG 플레이에 영향을 주지 않습니다.

실제 PNG 파일을 전달받으면 다음 명령으로 원본 바이트를 보존해 정리할 수 있습니다.

```sh
node scripts/import-rainbow-sources.mjs /path/to/color.png /path/to/outline.png
```

저장 위치는 `public/assets/source/rainbow-child/`입니다. `color-reference.png`, `outline-reference.png`, 크기와 SHA-256을 담은 `sources.json`이 만들어집니다. 기존 파일은 덮어쓰지 않습니다. [원본 폴더 설명](public/assets/source/rainbow-child/README.md)을 참고하세요.

## 개발 및 검증

Node.js 24와 npm을 사용합니다. 기존 체크아웃에서 실행합니다.

```sh
npm ci
npm run dev
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
```

브라우저 다운로드가 제한되어도 시스템 Chromium이 있으면 다음과 같이 실행할 수 있습니다.

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

프로덕션 동작은 `npm run build` 후 `npm run preview`로 확인합니다. 서비스 워커는 프로덕션에서만 등록합니다. Vite 기본 경로는 `/kids-color-by-number/`입니다.

단위 테스트는 색상 순서, 자동 전환, 되돌리기, 저장 데이터 검증, 25색 도안 계약과 원본 복사 스크립트를 검사합니다. Playwright는 800×1280 터치 화면과 360px 모바일 화면에서 43개 영역을 실제로 터치해 완성합니다. 저장/이어하기, 강조/힌트, 확대, 초기화 확인/취소, 키보드 입력, 25색 팔레트 자동 스크롤, PNG 파일/해상도/색상 픽셀, 오프라인 재실행을 검증합니다. 실제 갤럭시탭/Samsung Internet의 수동 검증은 별도입니다.

## 도안 데이터 구조

- `src/data/types.ts`: `Drawing`, `Region`, `PaintColor` 계약
- `src/data/drawings.ts`: 정식 카탈로그, 등록 목록, 대표 도안
- `src/data/rainbow-child/palette.ts`: 한글 색상 이름·HEX·1~25 순서
- `src/data/rainbow-child/regions.ts`: 닫힌 path·영역 ID·색상 번호·숫자 좌표
- `src/data/rainbow-child/index.ts`: 제목·viewBox·revision·비색칠 장식
- `src/Artwork.tsx`: 공통 SVG 렌더러와 영역별 터치/키보드 입력
- `src/engine.ts`: 순서 제한·진행 상태·저장 검증

새 정식 도안은 같은 형식의 폴더에 작성하고 카탈로그 ID로 `drawings`에 등록합니다. `featuredDrawing`을 바꾸면 홈 대표 도안도 교체할 수 있습니다. 색상마다 한 영역 이상이 있어야 하며 `colors`는 번호 순으로 정렬합니다. 닫힌 영역을 만들고 숫자를 실제로 보이는 내부에 둔 뒤 모든 영역을 터치해 검증하세요. 번호와 가는 장식은 별도 터치 대상을 만들지 않습니다. `paintWith` 장식은 지정한 영역의 색칠 상태를 따르며 자체 목표가 아닙니다.

기존 정식 도안의 영역 구성이 바뀌면 `revision`을 올립니다. 저장 키가 도안 ID와 revision으로 분리되어 이전 좌표/ID를 잘못 복원하지 않습니다.

## 기능과 로컬 저장

현재 색상의 영역은 미색·점선 테두리로 표시하고 다른 번호의 터치를 거절합니다. 힌트는 남은 영역 하나를 강조하며 전체 보기로 돌아갑니다. 100~300% 확대와 스크롤 이동, 한 영역씩 되돌리기, 확인 후 초기화를 지원합니다. 팔레트는 현재 색상으로 자동 스크롤되지만 순서를 임의로 건너뛸 수 없습니다.

색칠·되돌리기·초기화는 이 브라우저의 `localStorage`에 즉시 저장합니다. 기기/브라우저/사이트 주소에 따라 기록이 분리되며 서버 전송이나 계정 동기화는 없습니다. 브라우저 데이터 삭제/비공개 모드 종료/저장 공간 정리 시 기록이 사라질 수 있습니다. 저장 차단 시 안내하고 현재 세션의 색칠은 계속 허용합니다. 잘못된 저장 데이터는 무시합니다.

완성 시 축하 효과와 **1200×1500 PNG** 저장을 제공합니다. PNG에는 번호/힌트 테두리가 없고 얼굴 등 장식은 포함됩니다. `prefers-reduced-motion`이면 애니메이션을 끄고 Enter/Space로 영역을 칠할 수도 있습니다.

## 오프라인과 GitHub Pages

최초 온라인 접속 후 ‘오프라인 준비 완료’가 나타나면, 캐시된 앱과 번들에 들어 있는 SVG 데이터로 오프라인 새로고침·색칠·로컬 저장·PNG 생성을 지원합니다. 외부 이미지/API 없이 실행됩니다. 원본 PNG는 참고/보관 자료로, 필수 오프라인 캐시에 넣지 않습니다. 첫 방문/브라우저 캐시 삭제/서비스 워커 차단 상태에서는 오프라인 실행을 보장하지 않습니다.

`base`, manifest, 서비스 워커 범위는 모두 `/kids-color-by-number/`를 유지합니다.

1. 이 기능 브랜치의 PR을 검토해 `main`으로 병합합니다. 자동 병합은 하지 않습니다.
2. 저장소 Settings → Pages의 Source가 **GitHub Actions**인지 확인합니다.
3. `Deploy GitHub Pages` 워크플로가 새 `dist`를 게시합니다. 필요하면 수동 실행할 수 있습니다.
4. 게시 후 `https://leedb333.github.io/kids-color-by-number/`에서 확인합니다. 기존 탭은 닫았다 다시 열어 새 서비스 워커가 활성화되도록 합니다. 색칠 기록을 유지하려면 사이트 데이터를 삭제하지 마세요.

브랜치 업로드나 로컬 빌드는 실제 Pages 배포 완료를 의미하지 않습니다.
