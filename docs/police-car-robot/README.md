필수 터치 면은 135개이며 같은 색상의 서로 다른 면도 독립적입니다. 컬러 원본의 그라데이션을 평면색으로 단순화하고, 상단 경찰차와 하단 로봇의 원본 흑백 윤곽을 유지합니다. 직접 픽셀 IoU는 전체 94.56%, 모든 지정 비교 부위에서 91% 이상입니다. 원본 윤곽의 1픽셀 이내 재현율은 전체 99.998%입니다. 색상 이미지 전체가 픽셀 단위로 동일하다는 의미는 아닙니다.

재생성은 `scripts/police-trace/README.md`를 따릅니다. 그림 파일만 별도로 손으로 편집하지 않습니다.
