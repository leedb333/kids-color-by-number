# 무지개를 바라보는 아이 — 실제 원본

이 폴더에 업로드된 두 PNG를 직접 사용해 퍼즐을 추적했습니다. 파일은 변경하지 않았습니다.

- `rainbow-kid-color.png`: 컬러 완성본, 800×999. 퍼즐 색상 추출 기준.
- `rainbow-kid-line.png`: 흑백 도안, 800×999. 영역·외곽선·눈/입·단추/주머니 등 윤곽 추적 기준.
- `sources.json`: 원본 크기·SHA-256 기록. 테스트에서 실제 파일과 비교합니다.

`src/data/rainbow-child/`에는 이 파일들로부터 생성한 베지어 SVG 영역과 윤곽이 있습니다.
원본의 작은 닫힌 공간은 큰 목표와 함께 채우며 개별 터치/숫자 과제로 만들지 않습니다.
앱은 원본 PNG를 화면이나 PNG 출력의 배경으로 사용하지 않고 생성된 벡터만 사용합니다.
원본 이미지는 비교/보관 자료이므로 필수 오프라인 캐시에 넣지 않습니다.

재생성 절차는 `scripts/rainbow-trace/README.md`에 있습니다. 원본을 교체할 때는 해시,
닫힌 공간 번호와 그룹, 라벨 위치를 다시 검토하고 도안 revision을 올려야 합니다.
